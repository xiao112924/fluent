# PipePulse 通用液压声学网络最终验证报告

## 1. 当前完成的目标架构

PipePulse 现在具备两层明确分离的模型：

1. **液压声学网络层**：求解任意连接拓扑中的复压力和复体积流量；
2. **结构动力学层**：现有 Timoshenko 梁、预应力、结构边界和 HBM 保持独立。

新的预测模式为：

`cfg.fluid.pressure_field_model = 'acoustic_network'`

结构网格可以自动转换成 FETM 管路声学网络，同时允许添加 FETM 管段、集中阻力、液柱惯性、串联R-L、任意被动复阻抗、液体容腔/等效顺应性、端接、压力源、体积流量源以及带有限源阻抗的Thevenin压力源。

异构元件、源和端接内部采用 cell-array-of-structs，因此不同元件可以混合在同一个网络中。

## 2. 解析物理验证

### 匹配端传播

对均匀FETM管段设置特征阻抗端接，理论应满足 `|H|=1`、`phase(H)=-kL`。本次数值验证最大复误差为 `2.220e-16`。

### T形支路

对完全对称的双支路网络，最大两支路压力差为 `7.850e-17`，节点体积流量守恒残差为 `4.263e-25`。

### Thevenin / Norton 源

随机复阻抗算例中，两种等效源表示的最大误差为 `1.986e-15`。

### 容腔

100 mL液体容腔按 `Cq=V/K` 作为节点并联顺应性加入后，压力传递随频率连续变化，说明容腔/蓄能器可直接通过物理参数进入模型。

## 3. 2.8 实验算例

在现有结构边界不变时：

| 压力模型 | RMSE / g | MAPE |
|---|---:|---:|
| endpoint_constrained | 0.1247 | 26.37% |
| acoustic_network / matched termination | 0.2205 | 47.78% |
| single passive RLC termination trial | 4.3054 | 1014.11% |

已知入口、出口实测压力时，`endpoint_constrained` 仍是当前2.8实验最好的工程复现方式。只有测试管和一个简单被动终端不足以代表完整实验台；强行用单个被动RLC端阻抗拟合会把第7阶推到液柱半波共振附近，产生约12.3 g异常结构响应，因此没有再次修改 Kt/Kr/Ct/Cr/zeta。

## 4. 通用预测模式

只有泵/源参数、需要预测新管路时，使用 `acoustic_network`，并输入至少一种物理源信息：泵压力脉动+源阻抗、泵流量脉动或某节点已知压力。同时给出阀/节流、连接管段、容腔/蓄能器和终端阻抗等实际网络元件。

换新管路几何时只需重新生成结构/声学管段，不需要重新用Workbench标定压力场。

## 5. 推荐正式策略

- `endpoint_constrained`：当前2.8实验默认复现模式；
- `acoustic_network`：未来任意管路正式预测模式；
- `fetm_impedance`：单管单端阻抗诊断模式；
- `acoustic_bvp`：兼容模式，不推荐默认。

结构层继续使用当前 Timoshenko + 已验证边界/阻尼，不再通过结构边界补偿声学网络缺项。

本环境没有原生MATLAB运行时，因此数值物理验证由Python等价矩阵完成；MATLAB源代码通过静态接口/TDD及GitHub CI回归检查。
