# FETM + 声学阻抗升级验证报告

## 1. 本轮修正

新增 `fetm_impedance` 压力场，按照 OpenPulse 的一维 FETM 导纳矩阵：

\[
Y_e=\frac{i}{Z_v\sin(kL)}
\begin{bmatrix}
-\cos(kL)&1\\
1&-\cos(kL)
\end{bmatrix},
\qquad
Z_v=\frac{\rho c}{A}.
\]

与旧 `acoustic_bvp` 最大区别是：**FETM 模式只允许一个端点压力作为硬边界**，另一端必须使用声学阻抗。

当前实现支持：`anechoic`、`normalized_constant`、`normalized_rlc`、`specific_volume_impedance`，并支持一个统一的 OpenPulse-style proportional acoustic loss 参数。旧 `endpoint_constrained` 和 `acoustic_bvp` 均保留。

本算例修正声速为 `1287.2454 m/s`，特征体积阻抗为 `8.24335e9 Pa*s/m^3`，管路中心线总长 `0.5081571 m`。

## 2. 实测入口/出口压力能否由“单管 + 被动端阻抗”解释？

以入口压力为唯一已知源，利用实测复传递率 `H=Pout/Pin` 反推每阶所需端阻抗。普通被动液压边界应满足 `Re(Zt)>=0`。

反推结果中，第 1、2、3、8 阶需要负实部阻抗；反过来把出口作为源，第 4、5、6、7 阶需要负实部阻抗。因此无论选哪一端作为单一声源，当前两端实测压力都不能由“单均匀管 + 单被动终端”完整解释。

这说明实验管路的外部泵、阀、连接管路、容腔等声学网络参与了压力传递。

## 3. 统一被动端阻抗拟合

入口作为声源时：被动常复阻抗复传递归一化 RMS = `0.941`；统一被动 RLC = `0.908`；即使增加一个全频统一比例声学损耗也只能降到 `0.533`，且对应 `eta_a≈0.733`，损耗过大，不能作为可信通用声学边界。

出口作为声源时，最好的一类被动模型复传递 RMS 仍约 `0.806`。方向交换不能解决问题。

## 4. 固定原结构边界后的响应

固定之前较可信的结构边界：

- `Kt=1.598676e7 N/m`
- `Kr=1.237086e3 N*m/rad`
- `Ct=758.545 N*s/m`
- `Cr=1.900684 N*m*s/rad`
- `zeta=5%`

旧 `endpoint_constrained` 基准：

`[0.847366, 0.670092, 0.331963, 0.190447, 0.138021, 0.295398, 0.252328, 0.083900] g`

FETM 无反射端：

`[0.291313, 0.531839, 0.484909, 0.524488, 0.203333, 0.179595, 0.074372, 0.018284] g`

统一被动 RLC 端：

`[0.825523, 0.657152, 0.438978, 0.468998, 0.285147, 1.081203, 12.308631, 0.375401] g`

其中被动 RLC 在第7阶重新出现 `12.309 g` 的异常放大，说明它为了逼近端点压力传递，把系统推到了接近声学半波共振的位置。

## 5. 与实验的误差

| 压力场 | RMSE / g | MAPE |
|---|---:|---:|
| endpoint constrained | 0.1247 | 26.37% |
| FETM anechoic | 0.2205 | 47.78% |
| FETM passive RLC | 4.3054 | 1014.11% |

当前工程线性压力场仍明显优于没有足够外部网络信息的 FETM 模型。

## 6. 为什么本轮没有重新识别 Kt/Kr/Ct/Cr/zeta

这是有意的物理门槛。若先让声学模型错误，再让结构边界优化器补偿，会再次得到阻尼撞下限、刚度严重偏移、模态被破坏的伪识别。

由于本轮单被动阻抗 FETM 没有通过压力传递合理性门槛，所以结构边界保持之前可信值，不做新的强行识别。

## 7. 当前结论

1. FETM + impedance 的程序能力值得保留，它比双端硬压力 BVP 更物理。
2. 对当前2.8实验，单个被动端阻抗模型不足以描述外部液压回路。
3. 第7阶异常不是简单数值Bug；接近液柱半波频率时，错误/过简化端阻抗确实会把内部压力和结构响应大幅放大。
4. 当前 `endpoint_constrained` 仍应作为2.8工程计算默认值。
5. 下一步真正需要的是外部液压网络模型：泵源阻抗、阀/节流阻抗、连接管段、容腔/蓄能器等，而不是继续识别结构支撑参数。
6. 如果能获得泵出口/阀端的压力-流量关系或系统原理图，FETM 可以自然扩展为多管段网络，这才是通用预测程序需要的最终声学边界。

本环境无原生 MATLAB，因此数值响应使用与 MATLAB 方程一致的 Python 镜像完成；MATLAB源代码本轮通过静态回归测试验证。
